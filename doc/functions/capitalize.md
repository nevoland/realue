# Function: capitalize()

> **capitalize**\<`T`\>(`value`): `Capitalize`\<`T`\>

Returns the provided string `value` with its first character converted to upper case.

## Type Parameters

• **T** *extends* `string`

## Parameters

• **value**: `T`

The string to capitalize. Must not be empty.

## Returns

`Capitalize`\<`T`\>

The capitalized string.

## Example

```ts
capitalize("option"); // "Option"
```
